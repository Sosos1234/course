# ТРЦ «Европа 27» — Информационный ресурс

Веб-сайт для торгово-развлекательного центра «Европа 27» (г. Липецк). Каталог магазинов-арендаторов, поиск по товарам и услугам с поддержкой морфологии русского языка.

## Требования

- PHP 8.0+
- MySQL 5.7+ / MariaDB 10.2+
- Composer (опционально, для phpMorphy)

## Установка

1. **Опционально: установить зависимости через Composer** (для морфологии):

```bash
composer install
```

2. **Настроить конфигурацию** в `config/config.php`:
   - Параметры подключения к БД (host, name, user, pass)
   - Пароль администратора (admin)

3. **Создать базу данных:**

```bash
php install.php
```

4. **Импортировать тестовые данные:**

Открыть в браузере: `http://localhost/index.php?page=import`

5. **Запустить сайт** через веб-сервер (Apache/Nginx) или встроенный PHP-сервер:

```bash
php -S localhost:8000
```

## Структура проекта

```
├── admin/          — Административная панель
├── assets/         — CSS, JS
├── config/         — Конфигурация
├── database/       — Схема БД
├── import/         — Импорт данных из JSON
├── src/            — Модели (Shop, Category, SearchEngine и др.)
├── views/          — Шаблоны страниц
├── index.php       — Точка входа
├── bootstrap.php   — Инициализация
├── install.php     — Установка БД
└── composer.json
```

## Функционал

- **Главная** — статистика, категории, превью магазинов, блок новостей, CTA
- **Магазины** — каталог с фильтрацией по категории и этажу, карточки с счётчиком товаров
- **Страница магазина** — вкладки по категориям товаров, карточки товаров/услуг
- **Навигация** — план этажей с магазинами по этажам
- **Новости и акции** — лента новостей из БД
- **О центре** — информация о ТРЦ, статистика
- **Контакты** — адрес, режим работы, горячая линия
- **Поиск** — по магазинам и товарам (Full-Text + phpMorphy)
- **Импорт** — загрузка данных из JSON (с опцией перезаписи)
- **Админ-панель** — управление (логин: admin)

## Маршруты

- `/index.php` — главная
- `/index.php?page=shops` — каталог магазинов
- `/index.php?page=shop&id=1` — страница магазина
- `/index.php?page=floors` — навигация по этажам
- `/index.php?page=news` — новости и акции
- `/index.php?page=about` — о центре
- `/index.php?page=contacts` — контакты
- `/index.php?page=search&q=кулинария` — поиск
- `/index.php?page=admin` — админ-панель
- `/index.php?page=import&clear=1` — импорт с перезаписью (включает загрузку новостей)

## phpMorphy

Библиотека морфологии (опционально). При отсутствии поиск работает в режиме LIKE. Установка через Composer: `grigoryangeo/phpmorphy`.
