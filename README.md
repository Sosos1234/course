# ТРЦ «Европа 27» — Информационный ресурс

Веб-сайт для торгово-развлекательного центра «Европа 27» (г. Липецк). Каталог магазинов-арендаторов, поиск по товарам и услугам с поддержкой морфологии русского языка.

## Требования

- PHP 8.0+
- MySQL 5.7+ / MariaDB 10.2+
- Composer (опционально, для phpMorphy)

## Установка

1. **Опционально: установить зависимости через Composer** (для морфологии):

```bash
composer install
```

2. **Настроить конфигурацию** в `config/config.php`:
   - Параметры подключения к БД (host, name, user, pass)
   - Пароль администратора (admin)

3. **Создать базу данных:**

```bash
php install.php
```

4. **Запустить сайт** через веб-сервер (Apache/Nginx) или встроенный PHP-сервер:

```bash
php -S localhost:8000
```

**Доступ из интернета:** см. [docs/BESPLATNYJ_HOSTING.md](docs/BESPLATNYJ_HOSTING.md) — бесплатный хостинг (InfinityFree и др.) с поддоменом.

5. **Импортировать данные:** войдите в админ-панель (`?page=admin`, логин: admin), затем перейдите в импорт (`?page=import`).

6. **Обновить fulltext у существующих товаров** (если данные импортированы до обновления):  
   `php update_product_fulltext.php` — добавит в индекс название и описание магазина для поиска по смыслу.

7. **Добавить колонку image для картинок магазинов** (если БД создана до обновления):  
   `php migrate_shop_image.php` — для загрузки своих фото магазинов в админке.

8. **Таблица вариантов товаров** (если БД создана до обновления):  
   `php migrate_product_variants.php` — создаёт таблицу `product_variants`. После этого выполните импорт заново (страница Импорт в админке) — товары получат подразновидности (например, «Умные часы» → Apple Watch, Samsung Galaxy Watch, Xiaomi Mi Band).

## Функционал

**Режим посетителя:**
- **Главная** — статистика, категории, превью магазинов, блок новостей, CTA
- **Магазины** — каталог с фильтрацией по категории и этажу
- **Товары** — все товары и услуги с указанием магазина, этажа, павильона; фильтры; у каждого товара — варианты (например, «Умные часы»: Apple Watch, Samsung Galaxy Watch, Xiaomi Mi Band)
- **Поиск** — по магазинам и товарам (Full-Text + морфология + синонимы/родственные слова), результаты с этажом и павильоном; поиск по смыслу (например, «сладкое» → кондитерские, выпечка; «телефон» → смартфоны, ремонт)
- **Навигация** — план этажей с магазинами
- **Новости, О центре, Контакты**

**Режим администратора** (после входа):
- **Админ-панель** — доступ к импорту, просмотр магазинов и товаров
- **Импорт** — загрузка данных из JSON (только для авторизованных)

## Маршруты

- `/index.php` — главная
- `/index.php?page=shops` — каталог магазинов
- `/index.php?page=products` — все товары с фильтрами (этаж, магазин, категория)
- `/index.php?page=shop&id=1` — страница магазина
- `/index.php?page=floors` — навигация по этажам
- `/index.php?page=news` — новости и акции
- `/index.php?page=about` — о центре
- `/index.php?page=contacts` — контакты
- `/index.php?page=search&q=кулинария` — поиск
- `/index.php?page=admin` — админ-панель
- `/index.php?page=import` — импорт (только для администратора)
