# Презентация курсового проекта

## Как открыть

1. **В браузере** — откройте файл `index.html` двойным щелчком или:
   ```bash
   # Из папки проекта
   xdg-open presentation/index.html
   # или
   start presentation/index.html   # Windows
   ```

2. **Через PHP-сервер** (если нужен доступ по сети):
   ```bash
   php -S localhost:8080 -t presentation
   ```
   Затем откройте: http://localhost:8080

## Управление

- **Стрелки** или **пробел** — следующий/предыдущий слайд
- **F** — полноэкранный режим
- **S** — режим докладчика (в отдельном окне)
- **Esc** — обзор всех слайдов
