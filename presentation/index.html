ТРЦ «Европа 27»

Информационный веб-ресурс

Курсовой проект

Цель проекта

  • Создание централизованного информационного ресурса для ТРЦ «Европа 27» (г. Липецк)
  • Каталогизация магазинов-арендаторов и их товаров/услуг
  • Удобный поиск для посетителей
  • Актуальная информация о новостях и акциях

Технологии

Серверная часть

  • PHP 8.x
  • MySQL / MariaDB
  • Архитектура MVC

Клиентская часть

  • HTML5, CSS3
  • JavaScript
  • Адаптивная вёрстка

Поиск: Full-Text Search + морфология (phpMorphy)

Структура сайта

  • Главная — статистика, категории, превью магазинов, новости
  • Магазины — каталог с фильтрацией по категории и этажу
  • Навигация — план этажей с расположением магазинов
  • Новости и акции — лента новостей
  • О центре — информация о ТРЦ
  • Контакты — адрес, режим работы, горячая линия

Функционал

  • Поиск по магазинам и товарам с учётом морфологии
  • Детальные карточки магазинов с вкладками товаров по категориям
  • 5–10 товаров/услуг на каждый магазин
  • Импорт данных из JSON с опцией перезаписи
  • Административная панель

База данных

  • categories — категории магазинов
  • floors — этажи
  • shops — магазины-арендаторы (57+)
  • products — товары и услуги
  • news — новости и акции
