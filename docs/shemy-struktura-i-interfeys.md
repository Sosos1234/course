# Схемы «Структура проекта» и «Интерфейс проекта»

Описание для самостоятельного рисования в Visio, Draw.io и т.п.

---

## 1. СХЕМА «СТРУКТУРА ПРОЕКТА»

Показывает иерархию **папок и файлов**.

### Корень
**ТРЦ Европа 27** (прямоугольник, центр сверху)

### Уровень 1 — папки и ключевые файлы (под корнем)

| Элемент | Тип | Подпись (закругл. прямоугольник) |
|---------|-----|----------------------------------|
| admin/ | Прямоугольник | Административная панель |
| assets/ | Прямоугольник | Стили, скрипты, изображения |
| config/ | Прямоугольник | Конфигурация, подключение к БД |
| database/ | Прямоугольник | Схема БД, начальные данные |
| import/ | Прямоугольник | Импорт данных из JSON |
| src/ | Прямоугольник | Модели, логика (Shop, SearchEngine…) |
| views/ | Прямоугольник | Шаблоны страниц (HTML+PHP) |
| index.php | Прямоугольник | Точка входа, маршрутизация |
| bootstrap.php | Прямоугольник | Инициализация, DI-контейнер |

### Стрелки
- От **корня** — стрелка вниз к каждой папке/файлу
- От каждой **папки** — стрелка к **подписи** (закругл. прямоугольник справа)

### Внутри папок (опционально)
- **admin/**: index.php
- **assets/**: css/, js/, images/
- **src/**: Shop.php, Category.php, Floor.php, News.php, SearchEngine.php, DataImporter.php, MorphyProcessor.php
- **views/**: layout.php, home.php, shops.php, shop.php, search.php, floors.php, news.php, about.php, contacts.php, 404.php
