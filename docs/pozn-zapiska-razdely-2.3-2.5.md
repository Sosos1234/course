## 2.3 Проектирование базы данных

База данных информационного ресурса ТРЦ «Европа 27» спроектирована в виде реляционной схемы на MySQL/MariaDB с использованием движка InnoDB для обеспечения целостности и поддержки транзакций.

**Основные таблицы:**

1. **categories** — категории магазинов (Продукты, Одежда и обувь, Детские товары, Электроника и др.). Поля: id, name, slug, sort_order.

2. **floors** — этажи ТРЦ. В реализованной системе используются два этажа (1 этаж — основной торговый уровень, 2 этаж — торговая галерея, услуги). Поля: id, number, name, description.

3. **shops** — магазины-арендаторы. Содержит информацию о названии, описании, категории, этаже, павильоне, контактах. Поле fulltext используется для полнотекстового поиска. Внешние ключи: category_id → categories, floor_id → floors.

4. **products** — товары и услуги арендаторов. Связаны с магазинами через shop_id (ON DELETE CASCADE). Поля: name, category, price, fulltext. Индекс FULLTEXT для поиска по названию и категории.

5. **news** — новости и акции. Опциональная привязка к магазину через shop_id (ON DELETE SET NULL).

**Связи:** Категории и этажи — справочники. Магазины ссылаются на категорию и этаж. Товары принадлежат магазинам. Новости могут быть привязаны к магазину.

**Индексы:** На таблицах shops и products созданы полнотекстовые индексы (FULLTEXT) по полям name, description, fulltext для обеспечения быстрого поиска по ключевым словам.

## 2.4 Проектирование системы поиска

Система поиска информационного ресурса ТРЦ «Европа 27» построена на взаимодействии двух модулей: MorphyProcessor (морфологическая обработка) и SearchEngine (поисковый движок).

**MorphyProcessor** — модуль векторизации и лемматизации. Использует библиотеку phpMorphy для приведения слов к нормальной форме. Методы: getBaseForm() — возвращает лемму слова; getAllForms() — все словоформы; lemmatizeArray() — лемматизация массива слов; prepareFullText() — подготовка текста для индекса. При отсутствии phpMorphy выполняется простой перевод в нижний регистр.

**SearchEngine** — модуль поиска. Метод search(string $query, int $limit) выполняет: предобработку запроса (очистка, разбиение на токены, фильтрация стоп-слов); лемматизацию через MorphyProcessor; построение булева выражения вида +лемма* для MATCH...AGAINST в режиме IN BOOLEAN MODE; выполнение запросов к таблицам shops и products; группировку результатов по типу (магазины, товары). При сбое FULLTEXT используется резервный поиск по LIKE.

**Поток данных:** Пользователь вводит запрос → контроллер передаёт строку в SearchEngine::search() → формируется массив [shops, products] → шаблон search.php отображает результаты. При отсутствии совпадений выводятся подсказки по категориям.

## 2.5 Проектирование пользовательского интерфейса

Пользовательский интерфейс информационного ресурса ТРЦ «Европа 27» разработан с учётом требований к удобству навигации и адаптивности.

**Структура макета.** Все страницы используют единый шаблон layout.php: фиксированный header с логотипом, строкой поиска и навигацией (Главная, Магазины, Навигация, Новости, О центре, Контакты); основная область main с контентом страницы; footer с контактной информацией и ссылками.

**Основные страницы:** Главная (home.php) — статистика, категории, превью магазинов, блок новостей; Магазины (shops.php) — каталог с фильтрами по категории и этажу, карточки с изображениями; Страница магазина (shop.php) — детальная информация, товары по вкладкам; Поиск (search.php) — поле ввода, результаты (магазины и товары), подсказки по категориям; Навигация по этажам (floors.php) — списки магазинов по этажам; Новости (news.php), О центре (about.php), Контакты (contacts.php).

**Адаптивность.** Вёрстка реализована на CSS Grid и Flexbox с медиазапросами для планшетов и мобильных устройств. Используется шрифт Outfit (Google Fonts), единая цветовая схема и скруглённые блоки для карточек.

**Элементы интерфейса.** Карточки магазинов содержат изображение, название, этаж, счётчик товаров. Страница поиска выводит результаты с группировкой и ссылками на детальные карточки. Фильтры на странице магазинов представлены выпадающими списками по категориям и этажам.
