# Схема «Структура сайта» для Microsoft Visio

Пошаговая инструкция по созданию диаграммы структуры сайта ТРЦ «Европа 27» в Microsoft Visio.

---

## Шаблон в Visio

**Файл → Создать** → выберите **«Блок-схема»** или **«Карта веб-сайта»** (Site Map).

---

## Элементы и расположение

### Уровень 1: Главная страница (центр, сверху)

| Параметр | Значение |
|----------|----------|
| Текст | **Главная** |
| Подпись | `index.php` |
| Фигура | Прямоугольник (основная) |
| Цвет заливки | Светло-оранжевый (#FFE4B5) или акцентный |
| Размер | 140×50 px |
| Позиция | Центр, верхняя треть листа |

---

### Уровень 2: Основные разделы (под Главной)

Расположите 6 блоков в один ряд под «Главная», соедините стрелками вниз от Главной к каждому:

| № | Текст | URL | Цвет |
|---|-------|-----|------|
| 1 | **Магазины** | `?page=shops` | Голубой |
| 2 | **Навигация** | `?page=floors` | Голубой |
| 3 | **Новости** | `?page=news` | Голубой |
| 4 | **О центре** | `?page=about` | Голубой |
| 5 | **Контакты** | `?page=contacts` | Голубой |
| 6 | **Поиск** | `?page=search` | Зелёный |

Размер каждого блока: ~100×40 px. Интервал между блоками: 20 px.

---

### Уровень 3: Дочерние страницы

**От «Магазины» и «Навигация»** — стрелка вниз к:

| Текст | URL | Примечание |
|-------|-----|------------|
| **Страница магазина** | `?page=shop&id=N` | Детальная карточка, товары/услуги |

**От «Поиск»** — стрелка к тому же блоку «Страница магазина» (результаты ведут на карточку).

---

### Уровень 4: Служебные разделы

Справа или внизу, пунктирными стрелками от «Главная»:

| Текст | URL | Цвет |
|-------|-----|------|
| **Админ-панель** | `?page=admin` | Серый |
| **Импорт данных** | `?page=import` | Серый |

---

## Схема связей (стрелки)

```
                    [Главная]
                        |
    +----+----+----+----+----+----+
    |    |    |    |    |    |    |
[Магазины][Нав][Нов][О центре][Конт][Поиск]
    |    |         |              |
    +----+---------+              |
           |                      |
      [Страница магазина] <-------+
           ^
           | (от Поиск)
    
    [Главная] - - - -> [Админ]
    [Главная] - - - -> [Импорт]
```

## Текст для блоков (скопировать)

| Блок | Строка 1 | Строка 2 |
|------|----------|-----------|
| Главная | Главная | index.php |
| Магазины | Магазины | ?page=shops |
| Навигация | Навигация по этажам | ?page=floors |
| Новости | Новости и акции | ?page=news |
| О центре | О центре | ?page=about |
| Контакты | Контакты | ?page=contacts |
| Поиск | Поиск | ?page=search&q=... |
| Страница магазина | Страница магазина | ?page=shop&id=N |
| Админ | Админ-панель | ?page=admin |
| Импорт | Импорт данных | ?page=import |

---

## Группировка (опционально)

В Visio можно сгруппировать:

1. **Публичные страницы** — Главная, Магазины, Навигация, Новости, О центре, Контакты, Поиск, Страница магазина
2. **Служебные** — Админ, Импорт

---

## Экспорт

После создания: **Файл → Сохранить как** → выберите нужный формат (.vsdx, .vsd или растровое изображение).
