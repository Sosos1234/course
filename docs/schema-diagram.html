Схема данных БД — ТРЦ «Европа 27»

categories
▪ id (PK)
▪ name VARCHAR(100)
▪ slug VARCHAR(100)
▪ sort_order INT
floors
▪ id (PK)
▪ number INT
▪ name VARCHAR(50)
▪ description VARCHAR(255)
shops
▪ id (PK)
▪ name, slug, description
▪ category_id → categories
▪ floor_id → floors
▪ pavilion, contact
▪ fulltext, created_at
products
▪ id (PK)
▪ shop_id → shops
▪ name VARCHAR(255)
▪ category, price
▪ fulltext, created_at
news
▪ id (PK)
▪ shop_id → shops (NULL)
▪ title, content
▪ published_at, created_at
Связи: categories (1) ──→ (N) shops  |  floors (1) ──→ (N) shops  |  shops (1) ──→ (N) products  |  shops (1) ──→ (N) news
