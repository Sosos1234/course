# Бесплатный хостинг: как выложить сайт в интернет

Для доступа с любого компьютера сайт нужно разместить на хостинге. Если один хостинг работает плохо — попробуйте другой.

---

## 1. HelioHost

**Сайт:** [heliohost.org](https://www.heliohost.org)

- Бесплатно, без рекламы
- PHP 8, MySQL
- Без ограничения по времени
- Часто быстрее, чем InfinityFree

Регистрация → Create → выберите поддомен → загрузка файлов через File Manager, БД через MySQL.

---

## 2. Zerif Hosting

**Сайт:** [hosting.zerif.id](https://hosting.zerif.id)

- 5 ГБ места, 400 баз данных
- Бесплатный SSL
- По отзывам — один из самых быстрых бесплатных хостингов

## Общие шаги (для любого хостинга)

1. Зарегистрируйтесь и создайте сайт/хостинг.
2. Создайте базу MySQL в панели.
3. Загрузите файлы проекта (File Manager или FTP).
4. В `config/config.php` укажите host, name, user, pass из панели.
5. Выполните `database/schema.sql` в phpMyAdmin.
6. Откройте сайт → Админ → Импорт данных.

---

## Деплой через GitHub

Многие хостинги поддерживают установку из Git:

1. Загрузите проект на GitHub.
2. В панели хостинга выберите «Установить из Git/GitHub».
3. Укажите репозиторий и настройте БД.

---

## Что проверить на любом хостинге

- PHP 8.0+
- Расширения: `pdo_mysql`, `mbstring`, `json`
- Доступ к MySQL (создание БД и пользователя)
- Возможность загрузки файлов (FTP или File Manager)

---

## После размещения

1. Запустите `install.php` или выполните `database/schema.sql` в phpMyAdmin.
2. Импортируйте данные через `?page=import` (после входа в админку).
3. Откройте сайт по выданному адресу (`вашпроект.infinityfreeapp.com` и т.п.).

Сайт будет доступен с любого устройства по этому адресу.
