# Доступ к сайту из другой сети (разные компьютеры, разные сети)

Когда два компьютера **не в одной сети**, нужен туннель из интернета к вашему локальному серверу.

---

## Вариант 1: ngrok (самый простой)

1. Зарегистрируйтесь на [ngrok.com](https://ngrok.com) (бесплатно).

2. Скачайте ngrok и установите:  
   [https://ngrok.com/download](https://ngrok.com/download)

3. На ПК, где запущен сайт:

   **Терминал 1** — запуск сайта:
   ```bash
   php -S 0.0.0.0:8000
   ```

   **Терминал 2** — запуск туннеля:
   ```bash
   ngrok http 8000
   ```

4. В выводе ngrok появится адрес вида:
   ```
   Forwarding   https://xxxx-xx-xx-xxx-xx.ngrok-free.app -> http://localhost:8000
   ```

5. Эту ссылку можно открыть **с любого другого компьютера** в интернете.

**Важно:** Пока ngrok запущен и сайт слушает порт 8000, ссылка будет работать.

---

## Вариант 2: localhost.run (без установки, через SSH)

Если есть SSH (Git Bash, WSL, Linux):

1. Запустите сайт:
   ```bash
   php -S 0.0.0.0:8000
   ```

2. В другом терминале:
   ```bash
   ssh -R 80:localhost:8000 localhost.run
   ```

3. В выводе будет ссылка вида `https://xxxx.lhr.life` — откройте её с другого ПК.

---

## Вариант 3: Бесплатный хостинг (постоянный адрес)

Если туннели не подходят — разместите сайт на бесплатном хостинге. Вы получите постоянный адрес вида `вашпроект.infinityfreeapp.com`.

**Подробная инструкция:** [docs/BESPLATNYJ_HOSTING.md](BESPLATNYJ_HOSTING.md)

Кратко:

- **InfinityFree** — бесплатно, PHP + MySQL, поддомен
- **000webhost** — бесплатно, PHP + MySQL
- **Beget** — бесплатный пробный период

Регистрация, загрузка файлов и настройка БД описаны в документе.
