  ТРЦ Европа 27 — настройка флешки для запуска без установки
═══════════════════════════════════════════════════════════

Сделайте ОДИН РАЗ дома, затем носите флешку в колледж.

───────────────────────────────────────────────────────────
ШАГ 1. Скопировать проект на флешку
───────────────────────────────────────────────────────────

Скопируйте ВСЮ папку проекта (europa27-new или как у вас) 
на флешку. Например: E:\europa27\

───────────────────────────────────────────────────────────
ШАГ 2. Скачать PHP (portable)
───────────────────────────────────────────────────────────

1. Откройте: https://windows.php.net/download/
2. Скачайте "VS16 x64 Thread Safe" (ZIP)
3. Распакуйте архив
4. Папку из архива (php-8.x.x) переименуйте в "php"
5. Положите папку "php" НА ФЛЕШКУ, в корень проекта:
   
   E:\europa27\
   ├── php\          ← папка с php.exe
   ├── index.php
   ├── ФЛЕШКА_ЗАПУСК.bat
   └── ...

───────────────────────────────────────────────────────────
ШАГ 3. Создать файл portable.flag
───────────────────────────────────────────────────────────

Создайте пустой файл "portable.flag" в корне проекта.
(Или просто дважды щёлкните ФЛЕШКА_ЗАПУСК.bat — он создаст 
его при первом запуске)

───────────────────────────────────────────────────────────
ШАГ 4. В колледже
───────────────────────────────────────────────────────────

1. Вставьте флешку
2. Дважды щёлкните start.bat
3. Откроется браузер с сайтом
4. Для остановки — закройте чёрное окно

───────────────────────────────────────────────────────────
ЕСЛИ НА КОМПЬЮТЕ ЕСТЬ XAMPP/OpenServer
───────────────────────────────────────────────────────────

Папка php на флешке не обязательна. Скрипт найдёт 
PHP в XAMPP или OpenServer автоматически.

───────────────────────────────────────────────────────────
Структура на флешке (пример):
───────────────────────────────────────────────────────────

   E:\europa27\
   ├── start.bat           ← двойной щелчок (или ФЛЕШКА_ЗАПУСК.bat)
├── portable.flag       ← пустой файл (создаётся сам)
├── php\                ← PHP portable
│   └── php.exe
├── index.php
├── config\
├── import\
├── ...остальные файлы проекта
